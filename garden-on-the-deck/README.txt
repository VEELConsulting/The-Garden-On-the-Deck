THE GARDEN ON THE DECK
Open index.html in any browser. Keep the "images" folder beside it.

To change a pepper: open index.html in a text editor, find the list that begins
"var peppers=[" and edit the name (n), description (d), type (t: "hot" or "plain")
or photo (img). To add a pepper, copy one line and put the new photo in images/.
The About page photos are the five <img> tags inside the "collage" section.
Spare photos are in images/extras.
